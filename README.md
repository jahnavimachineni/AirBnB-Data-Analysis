# 🏡 Airbnb Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing Airbnb listing data to uncover meaningful insights about pricing trends, availability patterns, customer preferences, and location-based performance. The analysis helps understand factors that influence rental prices and booking behavior, enabling data-driven decision making for hosts and stakeholders.

---

## 🎯 Objectives

* Analyze Airbnb listings to identify pricing trends.
* Understand how location, room type, and availability affect prices.
* Explore customer demand patterns.
* Perform data cleaning and preprocessing.
* Create visualizations to communicate insights effectively.

---

## 📂 Dataset

The dataset contains Airbnb listing information such as:

* Listing ID
* Host details
* Location (neighbourhood, latitude, longitude)
* Room type
* Price
* Minimum nights
* Number of reviews
* Availability throughout the year

*(Dataset source: Public Airbnb/Open Data platform)*

---

## 🛠️ Tools & Technologies

* **Python**
* **Pandas** – Data manipulation
* **NumPy** – Numerical operations
* **Matplotlib & Seaborn** – Data visualization
* **Jupyter Notebook / Google Colab** – Development environment

---

## 🔄 Project Workflow

1. **Data Collection**

   * Imported Airbnb dataset into the analysis environment.

2. **Data Cleaning**

   * Handled missing values.
   * Removed duplicates.
   * Converted data types.
   * Filtered unrealistic price values.

3. **Exploratory Data Analysis (EDA)**

   * Price distribution analysis.
   * Room type comparison.
   * Location-based pricing trends.
   * Availability vs demand analysis.

4. **Visualization**

   * Bar charts, histograms, and heatmaps.
   * Price comparison across neighbourhoods.
   * Review and availability trends.

---

## 📊 Key Insights

* Entire homes/apartments generally have higher prices than private/shared rooms.
* Listings in prime locations show significantly higher demand.
* Price variations depend heavily on neighbourhood and availability.
* Highly reviewed listings tend to maintain consistent bookings.
